# Salary Prediction Using Machine Learning

## Project Overview
A machine learning project that predicts employee salary based on years of experience.

## Algorithm
Linear Regression

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Dataset
30 records with YearsExperience and Salary columns.

## Model Performance
- MAE: 6286.45
- RMSE: 7059.04
- R2 Score: 0.9024

## Example Prediction
Experience: 5 years
Predicted Salary: 72440.66

## How to Run
pip install -r requirements.txt
python train_model.py
python predict_salary.py
